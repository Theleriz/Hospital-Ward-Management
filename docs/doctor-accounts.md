# Учётные записи врачей и назначения пациентов

Создавайте врачебные учётки из доверенной административной среды, подключённой к нужной MedBase БД. Учётка получает роль `Doctor`, а пациент назначается явно; врачебная очередь и закрытие заявки ограничиваются этими назначениями на стороне БД.

Из каталога `backend` запустите:

```powershell
$env:MEDBASE_ADMIN_DATABASE_URL = Read-Host 'Административная строка подключения к целевой БД'
python scripts/manage_doctor.py
Remove-Item Env:MEDBASE_ADMIN_DATABASE_URL
```

Инструмент интерактивно спросит внутренний ID учётки, отображаемое имя, бейдж, ID пациента и PIN (ввод PIN скрыт). Он сохраняет только bcrypt-хеш, создаёт роль `Doctor` и одно явное назначение. Повторное использование ID учётки или бейджа отклоняется без изменений. Перед запуском убедитесь, что целевая БД правильная; используйте административный доступ только в доверенной среде.

Удаление или передача назначения выполняется администратором отдельно после проверки полномочий; не назначайте пациента всем врачам. Скрипт не содержит имён сотрудников, PIN-кодов или данных пациентов.
